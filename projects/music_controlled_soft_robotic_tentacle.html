Music-Controlled Soft Robotic Tentacle

Abstract

This project was developed for Computational Approach to Music, where audio events generated in MAX/MSP were mapped to a string-driven soft robotic arm. The result was a tentacle-like robot that responded to the music in real time and moved with a grooving, expressive motion.

The goal was not just to trigger motion from sound, but to translate musical structure into visible rhythm, making the robot feel like a performative instrument rather than a passive actuator.

Project Overview

The system connected MAX/MSP to the actuator control pipeline, allowing musical input to influence the timing and intensity of string actuation. Because the robot is soft and compliant, the motion naturally produced a fluid response that aligned well with the dynamic qualities of music.

  • Music analysis and event generation were handled in MAX/MSP.
  • Audio features were mapped to actuator commands for the string-driven arm.
  • The soft robotic structure amplified the sense of dance-like motion.
  • The final behavior was designed as an expressive installation demo.

How It Worked

MAX/MSP Performance Layer

The music interface was built in MAX/MSP, where signals, timing cues, and musical gestures were prepared for robot control.

Actuation Mapping

Musical events were translated into control commands that drove the actuator strings and shaped the motion profile of the tentacle.

Soft Robotic Motion

The compliant structure gave the movement a natural sway, which made the robot feel expressive rather than rigid.

Live Demo Format

The project was presented as a performance-style installation, where the robot visually responded to the character of the music.

Results and Takeaways

Musical Responsiveness

The robot reacted to sound in a way that preserved rhythmic feel and motion continuity.

Expressive Behavior

The soft arm created an organic visual rhythm that matched the musical atmosphere.

Cross-Modal Mapping

The project demonstrated how audio features can be translated into physical motion for interactive art and robotics.
